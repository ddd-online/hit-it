## 单股持仓审视

```text
【个股持仓审视】名称（代码）
数据日期：YYYY-MM-DD
执行时间：YYYY-MM-DD HH:MM
口径：盘中快照 / 收盘复盘 / 盘后计划

结论：继续持有 / 条件持有 / 不继续持有 / 数据未获取
当日状态：涨停 / 炸板 / 上涨 / 下跌 / 平 / 停牌 / 未获取
价格承接：健康 / 临界 / 不健康 / 未获取；最关键数字
量能：健康 / 临界 / 不健康 / 未获取；注明盘中部分量或全天量
筹码：健康 / 临界 / 不健康 / 未获取；获利盘、集中度、质量
题材：健康 / 临界 / 不健康 / 未获取；扩散一句
消息：健康 / 临界 / 不健康 / 未获取；主要催化或风险

保留条件：……
失效条件：……
报告：report/个股审视/<数据日期>_<code>.md
不构成投资建议
```

## 约束

- 只写最终“可打板”和最多 3 只“只观察”；排除清单只写数量和主要原因。
- 每只股票控制在 4 行以内，不用宽表格。
- 数据日期必须来自 `data_date`；执行时间来自 `generated_at`。凌晨执行时两者可以不同。
- 不写“预计高开 X%”，只写可核验事实和触发/失效条件。
- 没有可打板时，第一行直接写“今日无可打板”，不要用观察票凑推荐。
- 第二梯队必须与打板名单分开；最多保留每题材一只，没有合格股票时写“本时点无第二梯队候选”。
- `09:25` 前写“开盘价未撮合”，不得出现 `-100%`；`09:25–10:30` 低晋级率写“退潮待确认”，10:30 后才写确认退潮。
- 第二梯队必须写 `core / ladder / D` 和 `状态上限`；`D` 缺样本、跨源快照或 `sample_complete=false` 时写“不可用”，不得给候选。
- 第二梯队摘要写执行时点量价、历史位置、筹码和情绪的最关键事实，不写机械总分。
- 有停牌最高板时必须写清“停牌高标”和连带排除数，不能把停牌写成低开、跌停或行情缺失。
- 单股摘要必须直接回答是否继续持有，不得只罗列指标；盘中量能必须标“盘中部分量”。
- 单股“继续持有”和“条件持有”都必须写保留条件与失效条件；行情日期不一致时写“数据未获取”。
