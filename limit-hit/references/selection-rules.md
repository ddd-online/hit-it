# 打板候选筛选细则

本细则的阈值都是默认值。用户提出个人阈值时优先使用，并在报告“口径”表里注明。

## 1. 只处理两种模式

| 模式 | 当日板数 | 次日目标 | 核心要求 |
|---|---:|---|---|
| 一进二 | 1 板 | 次日二板，优先拿到高开溢价 | 题材新、同题材扩散、首封早、换手不过热 |
| 二进三 | 2 板 | 次日三板，优先拿到高开溢价 | 有板块带动、历史筹码不失控、情绪未退潮 |

三板及以上不进入名单。板数未知、当日未封住、全天一字无法成交，也只观察或排除。

## 2. 硬过滤

任一条件不满足即不能再写“可打板”：

| 检查 | 默认处理 |
|---|---|
| ST、退市整理、停牌 | 排除 |
| 非沪深主板（创业板、科创板、北交所） | 排除 |
| 全天一字且无开板成交 | 列入“不可执行”，不算候选 |
| 首封在 14:00 后且开板 ≥5 次 | 排除 |
| 当日换手率 >35% | 排除，除非题材处于全市场唯一主线且用户明确放宽 |
| 近 20 日涨幅 >50% 且获利盘 >95% | 排除，属于兑现区追高 |
| 财务造假、立案调查、退市风险、重大违规、业绩预告暴雷 | 排除 |
| 仍在执行中的大额减持或解禁压力 | 排除或显著扣分后只观察 |
| 消息面无法核验 | 只能“只观察” |
| 只有该股涨停、同题材其余股票不涨 | 题材独涨，排除 |

## 3. 市场情绪门槛

先从当日报告中计算两组真实反馈：

- 昨日一进二：昨日 `board_count=1` 的股票，今日晋级率、高开率、平均开盘涨幅、平均收盘涨幅；
- 昨日二进三：昨日 `board_count=2` 的股票，今日晋级率、高开率、平均开盘涨幅、平均收盘涨幅。

当日报告要求 `quote_date == data_date`。两者不一致时，`yesterday_performance` 不是当日口径，必须标“数据未获取”并停止给出可打板结论。

昨日涨停样本必须来自 `report/涨停池/<previous_date>.json`；文件不存在时停止运行，并提示先执行 `scripts/save_limit_pool.py --date <prev_date>`。运行时不得自行拉取或回补昨日池，已有文件不得覆盖。

参考 `$limit-judge` 的两条硬规则：

- 昨日涨停样本今天集体低开、平均高开为负或最高板跌停 → 降低候选数量；最高板天地板/跌停或无法判断 → 本日只能“只观察”；
- 停牌最高板单列，不按低开、天地板、跌停或行情缺失处理；与其同行业或共享精确概念的当日 1/2 板候选排除；
- 单只竞价/开盘不是结论，必须同时看高开/平开/低开家数、平均与中位高开幅度。

默认判定：

| 状态 | 条件 | 动作 |
|---|---|---|
| 允许 | 封板率 ≥60%，昨日晋级率 ≥25%，炸板率 <35% | 正常筛选 |
| 偏弱 | 晋级率 15%–24%，或炸板率 35%–45% | 最多 1 只，候选分必须 ≥85 |
| 退潮 | 最高板较昨日下降，且晋级率 <15% | 默认无可打板 |
| 崩塌 | 跌停 ≥20 家且跌停 ≥涨停家数的 1/3，或正常交易的最高板天地板/跌停 | 无可打板，只做风险记录 |

“允许”不等于每只都推荐；还须通过题材和个股门槛。

停牌股不计入涨跌家数、平均/中位涨幅和晋级率分母。昨日最高板停牌时，先排除与其同行业或共享精确概念的候选，再评估剩余题材；若另有最高板正常交易，仍按正常最高板负反馈规则检查。

## 4. 题材强度

先按概念代码聚合，不按概念名称模糊匹配。一个题材必须能说明“为什么今天有多个涨停”，并检查未涨停成分股是否跟随。

### 4.1 题材基础分（100）

| 维度 | 分值 | 默认计分 |
|---|---:|---|
| 涨停宽度 | 25 | 当日同题材涨停 ≥5 家 =25；3–4 家 =20；2 家 =12；只有 1 家但昨日有延续 =5；否则 0 |
| 板块梯队 | 25 | 有 ≥3 板核心 + 2 板中军 + 首板补涨 =25；只有高标与跟风两层 =20；只有最高 2 板 =15；全是首板 =8；无梯队 =0 |
| 昨日到今日延续 | 20 | 昨日同题材涨停今日晋级率 ≥40% =20；25%–39% =14；1 家晋级 =8；集体断板 =0 |
| 未涨停扩散 | 15 | 未涨停成分股上涨占比 ≥70% =15；50%–69% =11；30%–49% =6；<30% =0 |
| 板块动能 | 5 | 今日与 5 日涨幅均 >0 且主力净流入 >0 =5；两项为正 =3；一项为正 =1；均负 =0 |
| 消息催化 | 10 | 数据日前 48 小时内出现可核验实质催化 =10；仅有旧逻辑 =3；无来源 =0 |

默认强度门槛：

- `≥80`：强题材，可产生候选；
- `60–79`：中性题材，最多“只观察”；
- `<60`：不进入候选。

### 4.2 未涨停股怎么读

从 `scripts/fetch_sector_leaders.py --board BK... --top 300 --compact` 取成分股扩散摘要；需要逐股核验时使用 `--json`。排除已涨停、炸板、跌停后统计：

- 上涨/下跌家数；
- 平均涨幅、中位涨幅；
- 近 5 日涨幅；
- 主力净流入；
- 涨幅居前的 1–3 只未涨停股，作为扩散证据，不加入候选。

强扩散要同时看到“多数未涨停股上涨 + 至少一只不是微涨而是主动跟随”。若板块指数上涨但多数成分股下跌，按权重股拉指数处理，不加分。

### 4.3 题材趋势

用最近 3–5 个交易日的 `report/涨停池/` 文件、涨停家数、连板高度、晋级率和炸板率判断阶段：

| 阶段 | 盘面特征 | 对 1/2 板候选的含义 |
|---|---|---|
| 点火 | 题材新、涨停 1–3 家、以首板为主，尚无 2 板核心 | 只关注最早启动的先动股，不追后排 |
| 扩散 | 涨停家数增加、出现 2–3 板晋级、未涨停股跟随 | 一进二优先，二进三看板块核心 |
| 加速 | 多股连板、最高 4 板以上、高换手，资金一致 | 只考虑板块绝对核心，跟风股不追 |
| 收缩 | 涨停家数减少、龙头断板/炸板/跌停、炸板率上升 | 不输出可打板 |

历史报告或板块数据不足时，写“题材趋势未确认”，不能仅凭当天涨停数量判断为扩散期。

## 5. 个股候选分

只在同一题材内比较。板块梯队、封板与洗盘、筹码、题材趋势先按 80 分累计，再归一到 100 分；消息面是独立硬门槛，不混入结构分。基本面不单独计分。模式门槛分开：

| 模式 | 结构分可打板 | 只观察 | 排除 |
|---|---:|---:|---:|
| 一进二 | ≥80 | 70–79 | <70 |
| 二进三 | ≥79 | 70–78 | <70 |

两者还都必须满足题材强度 ≥80。消息面硬门槛始终优先于分数。

| 维度 | 分值 | 判据 |
|---|---:|---|
| 板块梯队地位 | 20 | 龙头/板块核心且梯队完整 =20；首板中率先跟随的强势股 =15；普通跟风 =8；独涨或尾盘跟风 =0 |
| 封板与洗盘 | 25 | 首封 ≤09:35 计 6；≤10:00 计 5；≤11:00 计 3；14:00 后 0。开板 0 次计 6；1–2 次计 4；3–4 次计 1；≥5 次 0。封板资金/成交额 ≥30% 计 3；15%–29% 计 2；<5% 计 0。股价在近 3–5 日支撑上方、回调缩量后涨停放量、低开/下探后快速回封 =10；趋势正常但无洗盘证据 =5；高位放量长上影或尾盘勉强回封 =0 |
| 筹码结构 | 20 | 股东户数趋降、获利盘 50%–85%、90%成本集中度健康、现价不极端偏离平均成本、回调缩量 =20；三项满足 =14；两项满足 =8；高位筹码松动或获利盘 >95% =0 |
| 题材趋势 | 15 | 扩散期的一进二，或加速期且属于板块绝对核心 =15；点火期先动股 =10；题材仍在但个股非核心 =5；收缩期 =0 |

风险再扣分：

- 股东户数最新一期增加 >20%：扣 6；
- 获利盘 >90%：扣 8；筹码 90% 成本区间宽度/中值 >35%：扣 6；
- 近 3 日出现 ≥2 根放量长上影：扣 8；
- 当日换手 >35% 且 14:00 后才回封：扣 8；
- 最近 20 日已有 ≥3 次涨停：扣 4，避免重复消耗；
- 消息为澄清、减持、诉讼、处罚：直接排除。

### 5.1 消息门槛

消息不折算成结构分，直接决定候选状态：

- **通过**：数据日前 48 小时有原始催化，政策/产业消息明确指向题材核心，或公司存在直接业务/订单/产品催化；
- **只观察**：只有板块情绪、二手转述、旧逻辑或无法确认发布时间；
- **排除**：澄清、减持、诉讼、处罚、业绩暴雷或其他明确负事件。

历史回测没有可靠逐日消息快照，因此回测门槛只对应结构分；实盘“可打板”仍必须通过本消息门槛。

### 5.2 洗盘与出货式回封

洗盘必须由价格和量能共同证明，不能只看“开过板又封住”。

| 证据 | 偏洗盘 | 偏出货 |
|---|---|---|
| 日内路径 | 低开/下探后回升，快速回封 | 高开冲高后持续走弱，尾盘才封 |
| 开板次数 | 0–2 次 | ≥5 次 |
| 回封时间 | 早于 11:00 | 14:00 后 |
| 换手 | 一进二 5%–20%，二进三 8%–25% | >35%，尤其高位巨量 |
| 近 3–5 日量价 | 回调缩量，突破/涨停放量 | 放量长上影，次日承接弱 |
| 筹码 | 获利盘可控、成本区集中 | 获利盘 >95%、成本区过宽 |

没有分时数据时，只能根据开盘、最高、最低、收盘、首次/末次封板、开板次数和换手判断；证据不足写“洗盘未确认”，不能主观补成洗盘。

### 5.3 基本面边界

不例行用营收、净利、负债率、估值给短线情绪票加分或降级。只有以下硬风险需要查公告并排除：财务造假、立案调查、退市风险、重大违规、业绩预告暴雷、正在执行的大额减持或解禁。

筹码指标解释：

- 获利盘不是越低越好。50%–85% 说明上方套牢盘可控；>95% 容易遇到兑现；
- 筹码集中度数值越小越集中，但太低也可能是一致性过强，需与获利率、近期涨幅合看；
- 股东户数下降表示筹码趋集中，但披露有明显时滞，不能单独作为买点；报告必须写最新截止日和披露滞后。
- `metric_quality=degraded` 时，换手率和筹码由腾讯日 K 与当前流通股本近似，筹码维度不得按精确结果加分；`unavailable` 时筹码维度记 0 且不能据此进入“可打板”。

## 6. 次日高开判据

本 SKILL 不承诺具体开盘价。报告用“证据 + 条件 + 风险”描述：

1. 先列昨日同模式高开率与晋级率，说明当前环境的基准；
2. 再列本题材今日涨停宽度、未涨停扩散和核心高度；
3. 再列个股首封时间、开板次数、封板资金、换手、历史涨幅和筹码；
4. 最后给出可执行条件：
   - 盘中买入：首次封板或回封时封单/成交额不低于默认 15%，且同题材至少 1 只未涨停股仍上涨；
   - 次日退出：以次日开盘为默认退出点；高开达到目标（默认 +2%）按计划获利离场，低开则按失效条件离场，不恋战；
   - 次日竞价量占比：竞价成交额 ÷ D 日全天成交额，3%–8% 为活跃，>15% 警惕高开出货，<1% 视为市场不关心；
   - 失效：核心炸板、题材涨停家数回落、候选低开低于默认 -2%、出现负公告。

9:30 后运行不能把全天成交额当竞价成交额，竞价量占比标“不可用”。运行报告只描述当日证据与条件，不写历史胜率，不承诺具体开盘价。

## 7. 一个题材只留一只

题材内按候选分降序，平分时按：

1. 首封更早；
2. 同题材连板高度更高；
3. 开板次数更少；
4. 消息更直接；
5. 流通市值更小但不低于用户限制。

其他高分股放进“题材内备选/排除”，不能进入“可打板名单”。同一股票命中多个题材时，归入最直接、消息最明确的一个题材，避免重复推荐。
