# limit-hit 板块第二梯队结构代理回测设计

日期：2026-11-19

## 目标

在现有 `limit-hit` 打板候选流程之外，增加一个只用于历史研究的结构代理：

1. 按执行时点查看当日涨停板块梯队；
2. 定位对应精确概念的沪深主板成分股；
3. 分成“打板股组”和“第二梯队组”，分别评估已涨停打板股与尚未涨停但满足买入条件的股票；
4. 检验未涨停股当日最终封板概率及次日开盘溢价；
5. 分别输出 09:40、10:00、10:30、11:00 四个执行时点的结果。

该能力用于规则研究，不进入正式实盘结论。

## 数据来源

| 数据 | 来源 | 限制 |
|---|---|---|
| 历史涨停成功池、首封/末封时间、开板次数、题材原因 | `fetch_limit_up_history.py` | 只有最终涨停样本，没有历史分钟盘口 |
| 个股日 K、开盘、最高、最低、收盘、成交量 | 现有腾讯/东财日 K 回退链 | 无法还原时点价格和盘中量比 |
| 精确概念板块及成分股 | `fetch_sector_boards.py`、`fetch_sector_leaders.py` | 只有当前成分快照，存在概念调整和幸存者偏差 |
| 连板数 | 请求区间前预热交易日连续池回算 | 无前序池时保持未获取 |

不得引入新的外部数据目录、第三方依赖或未经验证的历史分钟接口。

## 执行时点

固定支持四个时点：

- `09:40`
- `10:00`
- `10:30`
- `11:00`

每个时点独立生成一份报告，另生成一份横向比较摘要。

## 板块梯队代理

时点 T 的可见涨停样本只包括 `first_seal <= T` 的股票。

沿用现有题材聚合和强度逻辑：

- 同一题材至少 2 只可见涨停，或存在昨日同题材晋级；
- 默认最多保留 3 个题材；
- 题材内已首封股票作为打板股候选；
- 没有 `first_seal` 或首封晚于 T 的股票不得作为 T 时点可见打板股。

历史消息和当时板块扩散不可复现，因此题材判断只使用涨停宽度、板数梯队和昨日延续，不使用消息分。

## 精确概念与成分股

1. 从入围题材名称映射当前精确概念板块代码；
2. 取该概念当前沪深主板、非 ST 成分股；
3. 同一股票命中多个题材时，只进入最直接、最强的题材；
4. 当前成分表不是历史快照，报告中必须为此单列限制。

无法唯一定位概念板块时，该题材只保留打板股，不扩展未涨停候选，并记录原因。

## 未涨停股代理条件

未涨停股只能使用 D-1 及以前数据、D 日开盘价和时点前已知的首封状态筛选，不使用 D 日收盘结果决定入选。

### 硬条件

- 沪深主板、非 ST；
- 不属于时点 T 已首封的涨停股；
- `board_count` 不要求存在；
- D 日开盘价低于当日涨停价；
- D 日高开幅度在 `-3%` 至 `+5%` 之间；
- D-1 收盘价不低于 MA5 和 MA10；
- D-1 近 5 日涨幅在 `-3%` 至 `+15%` 之间；
- D-1 收盘位置处于近 20 日区间的 20% 至 85%；
- 日 K 至少 20 根。

### 排序

同一题材内依次按以下字段降序：

1. 题材强度；
2. D 日高开幅度更接近 `+3%`；
3. D-1 近 5 日成交量均值不过度萎缩；
4. 流通市值较小；
5. 代码稳定排序。

每个题材只保留一只未涨停股。跨题材按相同顺序选择。

## 交易与结果

- 两组分别以 10,000 元初始本金独立计算，不能合并资金；
- 每个交易日最多一笔；
- 退出价为 D+1 开盘价；
- 100 股整手，单笔使用当时总权益的 100%；
- 使用与现有回测相同的佣金、印花税和过户费；
- D+1 开盘缺失时记录缺口，不使用收盘价替代。

打板股组：

- 只取执行时点前已首封的股票；
- 执行时点后必须发生开板并重新封板；
- 买入价沿用 D 日涨停价；
- 未发生执行后回封的股票记“候选未回封”，不计成交；
- 其余执行规则与现有 limit-hit 回测一致。

第二梯队组：

- 买入价为 D 日开盘价；
- 若 D 日开盘已经是一字涨停或涨停价，无法按开盘价买入，跳过；
- 其余执行规则见下文。

每笔记录：

- 执行时点；
- 题材及题材强度；
- 股票代码、名称；
- D-1 结构字段；
- D 日开盘、收盘、最高、最低；
- D 日是否最终封板；
- D+1 开盘及溢价；
- 买入到次日开盘的净收益和期末本金。

## 汇总指标

每个时点分别输出：

- 两组各自的信号日数；
- 打板股组和第二梯队组的实际成交数；
- 当日最终封板率；
- 次日开盘正溢价率；
- 平均次日开盘溢价；
- 平均单笔净收益；
- 期末本金、净收益率、最大回撤；
- 月度汇总；
- 数据缺失和跳过原因。

状态固定为：

- `打板候选`：执行时点前已首封且满足现有打板条件；
- `候选未回封`：打板候选在执行后未发生开板回封；
- `第二梯队候选`：通过未涨停股代理条件；
- `当日封板`：第二梯队候选在 D 日最终进入涨停池；
- `次日溢价`：D+1 开盘高于 D 日收盘；
- `未成交`：无法按对应组买入价成交或行情缺失。

## 命令

新增独立脚本：

```bash
python backtest/limit-hit/backtest_sector_second_line.py \
  --start 20260101 --end 20261119 --capital 10000 \
  --times 09:40,10:00,10:30,11:00
```

报告写入当前工作区：

```text
report/回测/板块第二梯队_<time>_<start>_<end>.md
report/回测/板块第二梯队_时点对比_<start>_<end>.md
```

## 代码边界

- 新增脚本放在 `backtest/limit-hit/`，不放进 SKILL 目录；
- 复用历史涨停池、日 K、概念板块和选股基础函数；
- 不修改正式 SKILL 的“可打板”三态结论；
- 在验证结果前不把未涨停股加入正式候选名单；
- 新增 `backtest/limit-hit/sector-second-line-template.md`。

## 测试

至少覆盖：

- 时点前已首封过滤；
- 未涨停股硬条件；
- 涨停价和一字板无法按开盘价买入；
- 当日封板与次日溢价判定；
- 同一股票跨题材去重；
- 当前概念成分缺失时不伪造候选；
- 四个时点报告路径不覆盖；
- 原有涨停回测和全量单元测试不回归。

## 已知偏差

- 当前概念成分不是历史成分；
- 日 K 不能还原时点价格、量比和盘口；
- D 日开盘价买入只是用户指定的历史代理价；
- 无法验证真实排队、滑点和盘中封板可成交性；
- 结果不能外推为实盘收益；
- 所有报告必须写“不构成投资建议”。
