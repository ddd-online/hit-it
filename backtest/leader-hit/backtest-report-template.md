# leader-hit 主升样本回测

本报告是结构代理回测，不是完整 SKILL 实盘胜率。历史题材、公告、板块扩散、
真实逐日换手率和历史股票池未完整复现，不得把命中率外推为实盘收益。

## 固定口径

- 股票范围：沪深主板，启动前收盘价低于用户价格上限，默认 20 元。
- 样本切分：训练集用于找漏判原因和调整规则；测试集只在规则冻结后运行一次。
- 正样本：启动后 20 个交易日内收盘最大涨幅至少 30%、期末涨幅至少 15%，
  窗口内至少 2 次涨停，且启动后按收盘价计算的最大回撤不超过 18%。
- 启动前在 T-5、T-3、T-1 分别回放；任一为 `洗盘中` 或 `待启动` 即算结构命中。
  启动日命中：`启动初段`。
- 股票池命中：启动前或启动日出现 `建仓完成 / 洗盘中 / 待启动 / 启动初段`。
- 所有技能特征只能使用启动日及以前的数据；未来涨幅只用于定义正样本和验收。
